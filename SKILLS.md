# Agent Skills — Brightscope

## Provider and source audit
Inspect each provider adapter, terms, rate limits, provenance and timestamp handling.

## Data normalisation
Design stable schemas, identifiers and deduplication tests for incomplete or conflicting metadata.

## Frontend and API testing
Test loading, empty results, provider failure, timeout and malformed payload behavior.

## Security and privacy
Review API keys, external proxies, user-query handling, CORS and content security.

## Documentation
Write a plain-language explanation and a separate technical account of adapters, data flow and limitations.

Agents may prepare code and tests, but a human maintainer reviews and authorises merges and deployments.
