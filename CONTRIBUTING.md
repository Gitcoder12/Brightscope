# Contributing to Brightscope

Read README.md and FEATURE_UPGRADE_PLAN.md first. Check existing issues and PRs, select one bounded task, define acceptance criteria, create a feature branch and add tests with the change. Include exact commands, environment, results, data provenance and limitations in your PR. Update ACTIVITY_LOG.md only after the work exists in a commit or PR. Do not add secrets or route user content through untrusted services. Human maintainers approve merges and deployments.
