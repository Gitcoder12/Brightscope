# Agent Instructions — Brightscope

Read README.md, CONTRIBUTING.md, FEATURE_UPGRADE_PLAN.md and ACTIVITY_LOG.md before acting.

- Inspect current code and open PRs before edits.
- Work on one bounded issue at a time, on a feature branch.
- Preserve provider licensing, source attribution and user privacy.
- Add tests for malformed data, missing providers, rate limits and partial failures.
- Never add secret keys, expose credentials, or proxy user data through an untrusted service.
- Run checks and report exact commands/results; never invent successful validation.
- Update documentation and activity log, then open a PR.
- Do not merge, deploy or change account settings autonomously.
