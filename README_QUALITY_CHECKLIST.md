# Brightscope — README Quality Checklist

## Beginner reader
- [ ] States the use case and user in plain language.
- [ ] Explains the normal workflow with a concrete example.
- [ ] Setup commands include expected output and common errors.

## Technical reader
- [ ] Architecture, providers, formats and data flow match the code.
- [ ] Source attribution, timestamps, rate limits and failure behavior are documented.
- [ ] Tests and evaluation methodology are linked.
- [ ] Planned integrations are clearly separated from implemented features.

## Contributor
- [ ] Links roadmap, activity log, company fit and contributor instructions.
- [ ] Tasks are bounded and acceptance-tested.
